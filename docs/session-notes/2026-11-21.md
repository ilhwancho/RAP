# 2026-11-20~21 세션: 값 도움말 정렬 (UI.presentationVariant) V2 vs V4

## 만든 것 (Z5U, 패키지 `ZCIH_VH_TEST`, 소스 `ABAP/ZCIH_VH_TEST/`)
- `ZI_CIH_CurrencyVH_Test` (I_Currency 래핑 VH, `@UI.presentationVariant` Decimals DESC), `ZC_CIH_SOVHTest`(CurrencyCode 에 VH)
- 서비스 정의 `ZUI_CIH_SOVHTEST`, 바인딩 `ZUI_CIH_SOVHTEST_O2`(V2 UI), `ZUI_CIH_SOVHTEST_O4`(V4 UI) 게시
- 현재 상태: PV qualifier 없음 + 소비 쪽 qualifier 없음 (V2 정상·다이얼로그 키 정렬, V4 PV 정렬)

## 결론
- V2: `presentationVariantQualifier` 지정 시 값 도움말 깨짐(UI5 버그성 TODO 코드). 다이얼로그는 PV 무시(키 asc), 드롭다운(고정값)만 PV 정렬.
  어노테이션·로컬 주석·manifest 로는 다이얼로그 정렬 불가 → 컨트롤러 확장(`ui5/v2-valuehelp-sort/`)으로 해결.
- V4: 어노테이션만으로 자동완성·다이얼로그 모두 PV 정렬.
- 확인 버전: UI5 1.154.0(최신), 1.148.12(Z5U 런치패드) 외.
- 상세: `docs/cds/value-help-presentation-variant-v2.md`

## 메모
- V2 UI 주석은 `$metadata` 가 아니라 `/sap/opu/odata/IWFND/CATALOGSERVICE;v=2/Annotations(TechnicalName='<바인딩>_VAN',Version='0001')/$value`.
- V4 값 도움말 메타데이터는 `Common.ValueListReferences` 의 `srvd_f4/...` 별도 문서.
- 게시 직후 V2 `$metadata` 403(UCON) 수 분. V2 publish 는 `/sap/bc/adt/businessservices/odatav2/publishjobs`.
