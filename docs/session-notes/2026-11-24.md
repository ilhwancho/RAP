# 2026-11-24 세션: FE V4 Delete 버튼 숨기기 (manifest / 로컬 주석)

## 질문
List Report 앱의 리스트 리포트·오브젝트 페이지에서 Delete 버튼을 manifest 로 없애는 법.

## 결론
- OP 헤더: `content.header.actions` → `"DeleteAction": {"visible": false}` → 사용자 앱에서 동작.
- LR 테이블: `controlConfiguration` → `@...LineItem` → `actions` → `"StandardAction::Delete": {"visible": false}` 는 **UI5 1.151 이상만** 동작.
  사용자 앱(Z5U 런치패드 1.148 계열)에서 안 없어짐 → 하네스로 1.120~1.150 무시, 1.151/1.154 동작 실측.
- 대안: 앱 로컬 주석 `UI.DeleteHidden`(1.120·1.148 실측) 또는 `Capabilities.DeleteRestrictions/Deletable=false`.
- 사용자 뷰가 **파라미터 CDS** → 엔티티셋 타겟은 무시, **엔티티 타입 타겟**으로 `DeleteRestrictions` 넣어 해결 (containment `Set` 때문, 소스 근거 확인).
- 상세: `docs/fe/hide-delete-button-v4.md`

## 만든 것
- `tools/ui5-fe-delete-test/` : 판매오더 서비스로 FE V4 LR 을 띄워 Delete 버튼 표시를 버전별로 측정하는 하네스. SAP 객체 변경 없음.
